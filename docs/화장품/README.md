# 화장품 비정형 문서 세트 (가상 — 코스메디아㈜)

**전부 가공(fictional) 문서다.** 회사·브랜드·공급사·인명·로트·클레임은 모두 가상이며,
원료명/INCI명/법규명만 실제 사실을 그대로 사용했다. 실존 화장품 회사와 무관하다.

워크벤치의 **"화장품" 캔버스(빈 스키마)** 업로드 → 온톨로지 구축 → RAG/추론 테스트용.
램프 도메인의 통제 어휘에 의존하지 않고, 파서의 **구조적 패턴만** 따르므로
모든 엔티티는 `auto-create`(확신도 0.66)로 편입되고 타입은 사용자가 캔버스에서 재정의하면 된다.

생성: `node --experimental-strip-types scripts/gen-cosmetics.ts` (xlsx/docx/pptx/pdf)
      `python scripts/gen-cosmetics-assets.py` (png)
둘 다 결정적 — 같은 입력이면 같은 결과(난수·현재시각 미사용).
