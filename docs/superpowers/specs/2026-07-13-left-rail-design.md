# 좌측 아이콘 레일 + 드로어 설계

- 날짜: 2026-07-13 · 상태: 승인(구두) · 참고: Neo4j Browser 좌측 아이콘 레일
- 배경: 계층 뷰가 타입→서브타입→개체를 담당하며 좌측 타입 탐색기와 겹침. 좌측을 Neo4j식
  얇은 아이콘 레일로 바꿔 기본 접힘 → 아이콘 클릭 시 드로어로 펼침. 그래프/결과프레임 공간 확보.
- 정책 결정(확정): 아이콘 여러 개(예정 포함) · 기본 접힘 · 객체 타입만 활성, 나머지 준비중.

## 레이아웃

`.main` 그리드 좌측 컬럼(현 252px)을 **레일(48px) + 드로어(가변)**로:
- 드로어 접힘: 좌측 = 48px(레일만)
- 드로어 열림: 좌측 = 48 + 252px
- Workbench `leftPanel` 상태(활성 아이콘 id | null)로 그리드 컬럼 폭 토글(클래스 또는 인라인).
- 1180px 이하 반응형: 기존처럼 축소(레일은 유지, 드로어는 오버레이 또는 숨김 — 간단히 레일만).

## 컴포넌트

`components/LeftRail.tsx` (신규):
- 세로 아이콘 레일 — 아이콘 버튼 목록. props: `active: string|null`, `onSelect: (id|null)=>void`, `children`(활성 드로어 내용).
- 아이콘(위→아래):
  - `types` **▣ 객체 타입** — 활성. 클릭 → 드로어에 children(타입 탐색기) 표시.
  - `history` **🕐 히스토리** — 준비중(disabled, "준비중" 툴팁).
  - `saved` **🔖 저장 뷰** — 준비중.
  - `settings` **⚙ 설정** — 준비중.
- 활성 아이콘 하이라이트. 같은 아이콘 재클릭 → onSelect(null)(접기). 다른 아이콘 → 전환.
- 준비중 아이콘 클릭 → 무동작(또는 토스트 없이 흐림 유지).
- 드로어: 활성일 때만 레일 오른쪽에 렌더(children). 헤더에 패널명 + 접기(✕).

SourcePanel(타입 탐색기)은 그대로 재사용 — LeftRail 드로어 children 으로 전달. SourcePanel 내부 무변경
(이미 타입 탐색기만 남음). `.side.left` 스타일은 드로어 컨테이너에 맞게 조정.

## 상호작용

- 기본: 접힘(레일만). 첫 진입 시 그래프 넓게.
- ▣ 클릭 → 타입 탐색기 드로어. 타입/서브타입 클릭은 기존대로 그래프 필터(Workbench onSelectType/Subtype 유지).
- 재클릭·✕ → 접기.
