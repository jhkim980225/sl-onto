# 신규 설계 추론 UI 재배치 — 조건·실행·결과 한 컬럼(A안)

- 날짜: 2026-07-14 · 상태: 승인(구두)
- 배경: 신규 설계 추론의 조건 입력(시장·광원·형상)이 **하단 스텝바**에, 실행 버튼은 **상단 바**,
  결과(체크리스트)는 **우측 패널** — 세 모서리로 흩어져 흐름이 어색. 입력→실행→결과를 우측 한 컬럼에 모은다.

## 변경

1. **하단 Stepper**: 조건 폼 제거 → 순수 3단계 스텝바로 정리. (Stepper props 에서 condition/onChangeCondition/editable 제거)
2. **우측 패널 "설계 조건" 헤더**: rightPanelMode === "checklist" 일 때, Checklist 위에 조건 폼 블록을 렌더:
   - 시장·광원·형상 입력(기존 Stepper 인풋 이관). 부품 앵커 선택 시 "부품 앵커: <라벨>" 배지 + 앵커 해제 없이 표시.
   - **▶ 추론 실행** 버튼(이 폼이 실제 재실행 트리거). 실행 중 로딩·비활성.
   - 그 아래 기존 Checklist(결과) 그대로.
   - 입력→실행→결과가 위→아래 한 흐름.
3. **상단 바 버튼** `▶ 신규 설계 추론` / `▶ '부품' 설계 검토`:
   - 동작 변경: 즉시 실행 대신 **패널 열기 + 최초 1회 실행**(rightPanelMode="checklist" + handleRunScenario).
   - 이후 조건 바꿔 재실행은 패널 안 "추론 실행" 버튼으로. (상단 버튼은 진입점, 패널 버튼은 반복 실행)
   - 부품 앵커 라벨 로직(inspectorObj item)은 상단·패널 양쪽 일관.

## 컴포넌트

- 조건 폼 블록은 새 `components/DesignConditionForm.tsx`(입력 3종 + 앵커 배지 + 실행 버튼) — Workbench 가
  checklist 패널 상단에 렌더. Checklist.tsx 는 무변경(결과만).
- editable 판정: 기존 `stage >= 2 && !scenarioTriggered` 대신, 패널에서는 항상 편집 가능(재실행 위해).

## CSS

`dc-` 접두: 조건 폼(우측 패널 상단, 입력 인라인·라벨), 실행 버튼(btn-primary 재사용), 앵커 배지. 기존 토큰 재사용.
하단 botbar 의 `.cond` 관련 스타일은 스텝바에서 제거(폼 이관).

## 범위 제외 (YAGNI)

- 조건 프리셋·저장 · 시장 드롭다운(자유 입력 유지) · 다중 조건 비교.
