# 계층(택소노미) 뷰 — 탑다운 노드-링크 설계

- 날짜: 2026-07-13 · 상태: 승인(구두) · 참고: Protégé OntoGraf / 클래스 계층
- 배경: 그래프를 온톨로지 툴답게 — 포스 그래프 외에 택소노미(타입→서브타입→개체)를 위→아래로
  펼치는 계층 뷰를 추가. "지식 분류 구조"를 직관적으로 보여준다.
- 정책 결정(확정): 계층 축 = **택소노미**(타입→서브타입→개체) · 렌더 = **노드-링크 다이어그램** ·
  데이터 범위 = **전체 온톨로지**(현재 뷰 아님 — 구조 브라우저) · 개체 클릭 = **Graph 뷰로 점프+포커스**.

## 통합

결과 프레임 토글에 4번째 뷰: `[Graph | 계층 | Table | RAW]`. 포스 그래프(Graph.tsx) 무수정 —
신규 컴포넌트 `components/HierarchyView.tsx`. Table/RAW를 붙인 것과 동일한 패턴(재작성 금지 컨벤션 준수).

## 계층 구조

`온톨로지(가상 루트) → 타입(9) → 서브타입 → 개체` 탑다운. 개체 폭주 방지: **서브타입은 기본 접힘,
클릭 시 하위 개체 펼침**. 서브타입 없는 타입(proj/master/spec 등)은 타입 아래 개체 직접(접힘 기본).

## 데이터 범위

전체 온톨로지 기준(캔버스 포커스 무관). Workbench가 이미 보유한 전체 그래프 노드 + getMetamodel()
(타입/서브타입 정의·라벨·색)을 입력으로. Table/RAW/오버뷰가 "현재 뷰"인 것과 의도적으로 다름 —
계층은 스냅샷이 아니라 클래스 지도.

## 렌더 (하드롤 SVG, 새 의존성 없음)

포스 그래프처럼 손수 SVG. 3레벨 얕아 tidy-tree 1차 배치로 충분:
- depth → y(레벨별 고정 y), 리프 개체를 균등 간격으로 x 배치 후 부모는 자식 x 중앙.
- 접힌 노드는 자식을 레이아웃에서 제외(폭 관리).
- 박스(타입/서브타입/개체) + 수직 링크선. 타입·서브타입 색은 typeStyles.
- viewBox 팬(드래그)·줌(휠/버튼). 그래프 줌 로직 참고하되 독립 구현.

## 상호작용

- 타입·서브타입 박스 클릭 → 하위 펼침/접기(로컬 상태 Set).
- 개체 박스 클릭 → `onSelectNode(id)`: Workbench가 setViewMode("graph") + handleNodeClick(id)로
  Graph 뷰 전환 + 그 노드 포커스.
- 팬/줌. 접기 상태는 뷰 전환해도 유지(컴포넌트 마운트 유지 — display:none 토글).

## 데이터 준비 (순수 함수, 테스트)

`lib/taxonomy.ts`:
```
buildTaxonomy(nodes: Node[], metamodel: Metamodel): TaxNode
```
TaxNode 트리(kind: "root"|"type"|"subtype"|"instance", id, label?(개체만 원 라벨), typeId, stId?, count, children).
- 타입별 노드 그룹핑 → 서브타입(st)별 하위 그룹 → 개체. st 없는 노드는 타입 직속(또는 "미분류" 서브노드).
- doc 타입 포함 여부: 포함(근거 문서도 클래스) — 단 개체 수 많으면 접힘 기본이라 무해.
- 색·한글 라벨은 컴포넌트가 typeStyles/metamodel로 입힘. lib은 구조·카운트·raw id만.

## 테스트

- st 없는 노드는 미분류/타입직속 처리 일관.
- 빈 입력 → 루트만.

## 범위 제외 (YAGNI)

- 개체 간 관계선(HAS_FAILURE 등) — 계층 뷰엔 안 그림(Graph 뷰 몫). 계층은 순수 분류 구조.
- 편집·드래그 재배치·다중 루트 선택 · 서브타입 다층(1차 단층 유지).
