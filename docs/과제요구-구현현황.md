# 과제 요구 대비 구현 현황

> 작성일: 2026-07-06 · 기준: FEDA K8s **v7 배포본** + 로컬(구축 연출 속도 개선 반영)
> 표기: ✅ 됨 · 🔶 부분/수단 다름 · ❌ 안 됨
> 상세 설계·결정 기록은 각 링크 문서 참조.

## 한눈에 보기

| 영역 | 요구 항목 | 상태 |
|---|---|---|
| 비정형문서 분석 | 문서 형태 분석 + 형태별 최적 파싱 | ✅ (텍스트 문서 범위) |
| | 문서·이미지 내 텍스트 파싱 → DB 구축 | 🔶 문서 ✅ / 이미지 OCR ❌ / 영속 DB ❌ |
| | 외부 데이터 크롤링(논문·커뮤니티) | ❌ (의도적 범위 제외) |
| 구조화·온톨로지 | LLM으로 부품/고장모드/원인/조치 구조화 | 🔶 구조화 ✅ (규칙 기반) / LLM ❌ |
| | 부품/고장모드/원인/차종/법규 객체·관계 정의 | ✅ (객체 9종 · 관계 12종) |
| 의미 기반 검색 | RAG 기반 조건 필터 | 🔶 조건 필터 ✅ (규칙·그래프) / RAG ❌ |
| | 벡터 의미 검색 색인 | ❌ (의도적 미채택 — 결정 기록 있음) |
| | 웹에서 자연어 질의 | ✅ |
| FMEA 초안 생성 | 입력: 2D 도면 | ❌ (VLM 확장 영역) |
| | 입력: BOM | 🔶 구성 관계로 대체 / 파일 파싱 ❌ |
| | 유사 조건 과거 사례 검색 | ✅ |
| | 고장모드 후보 | ✅ |
| | 체크리스트 + 근거 출처 | ✅ |
| | FMEA 초안 생성(문서) | ✅ (DFMEA xlsx 다운로드) |

**전체 패턴**: 기능 목표는 규칙·그래프 기반으로 대부분 충족. "LLM·벡터·RAG"라는 **수단 키워드는
의도적 보류**(한국어 임베딩 변별 실패, 사내 vLLM 쿼리당 60초대)이며, 각각 교체 슬롯만 설계된 상태
— "미구현"이 아니라 **결정 기록이 있는 보류**. 이미지·도면 이해(OCR/VLM)와 외부 크롤링은 미착수 확장 영역.

## 1. 비정형문서 분석

### ① 문서 형태 분석 및 형태별 최적 파싱 — ✅ 됨 (텍스트 문서 범위)

단순 확장자 분기가 아니라 **문서 내부 형태까지 감지해 파싱 전략을 바꾼다** (`lib/ingest/`):

- **xlsx**: 정형 시트는 컬럼 매핑, 실무형 시트는 휴리스틱 — 헤더 행 자동 탐지(앞 15행 스캔),
  2행 병합 헤더, 세로 병합 셀 전파, 동의어 컬럼명 매핑(부품명/품명/item…)
- **pptx**: 앵커 섹션 파싱(프로젝트:/이슈:/원인분석/대책), 산문형 8D는 자유 텍스트 엔티티 스캔 폴백
- **docx**: "키: 값" 필드 파싱 + 산문 리포트 폴백
- 측정: 실무형 지저분한 샘플에서 구파서 **0객체/0관계 → 견고 파서 42객체/36관계** (`data/real-samples/`)

상세: [features/ingestion.md](features/ingestion.md)

### ② 문서·이미지 내 텍스트 파싱 → 데이터베이스 구축 — 🔶 절반

- ✅ **문서 텍스트 → 지식베이스**: 34개 문서 → 온톨로지 170 객체/2,156 관계, 전 객체 원본
  근거·확신도 연결. 증분 인제스천(새 문서 1건 실시간 병합)까지 동작.
- ❌ **이미지 내 텍스트(OCR)**: 스캔 PDF·표 사진·도면 주석 못 읽음 — Docling(Python 사이드카)/VLM
  확장 경계. 결로 설계도는 실도면 파싱이 아니라 온톨로지 링크된 SVG.
- ❌ **영속 DB**: 인메모리 저장소 — 재시작 시 `data/sources`에서 재구축(업로드분 소실).
  Postgres 교체 지점은 `lib/store.ts` 하나로 설계됨.

### ③ 외부 데이터 크롤링(논문·커뮤니티) — ❌ 안 됨

미착수. MVP 범위에서 의도적 제외, 확장기 분류 ([requirements.md](requirements.md) §4).

## 2. 문서 구조화 · 지식 온톨로지 구축

### ① 파싱 데이터를 LLM으로 부품/고장모드/원인/조치 필드 구조화 — 🔶 기능 됨 · 수단(LLM) 안 씀

구조화 결과물은 나온다: 원문 → 표준 객체 매핑(통제 어휘 + 동의어 사전), 미등록 값 auto-create
(id `AUTO_*`, 확신도 0.66), 원본값 보존 + 확신도 티어(1.00/0.95/0.82/0.72). 단, 엔진이 **LLM이
아니라 결정론적 규칙**(`lib/ingest/normalize.ts`) — 인제스천 경로에는 LLM 슬롯 자체가 없음.

보류 이유(결정 기록): 좁고 통제된 도메인 어휘에서는 규칙이 더 빠르고 재현 가능. 사내 vLLM은
쿼리당 60초대로 인제스천에 비현실적.

### ② 부품/고장모드/원인/차종/법규 등 객체·관계 정의 — ✅ 완전히 됨

- **객체 9종**: item(부품)·fm(고장모드)·cause(원인)·action(조치)·reg(법규)·proj(프로젝트, 차종은
  속성)·master(설계표준)·spec(고객스펙)·doc(근거문서)
- **관계 12종**: HAS_FAILURE·CAUSED_BY·MITIGATED_BY·UNDER_REG·DRL_REG·REF_MASTER·CONSISTS_OF·
  OCCURRED_IN·SIMILAR·THERMAL_RISK·SPEC_OF·EVIDENCED_BY (+ 시나리오 NEW_DESIGN_OF/TARGET_MARKET)

상세: [data-model.md](data-model.md)

## 3. 의미 기반 검색

### ① RAG 기반의 조건 필터 — 🔶 조건 필터 됨 · RAG 아님

"조건에 맞는 것만 걸러 답을 구성"하는 동작은 있음: 지역 필터(북미 질의에 유럽 법규 배제),
유형 의도 필터(원인/조치/법규…), 신규 설계 조건 기반 그래프 탐색(체크리스트). 단
**R(검색)→G(LLM 생성)** 구조가 아니라 검색 결과를 템플릿으로 조립. RAG 전환 이음새는 설계됨
— 탐색 결과를 컨텍스트로 LLM 생성, `infer()` 시그니처 유지 ([features/inference.md](features/inference.md)).

### ② 벡터 의미 검색 색인 — ❌ 안 됨 (의도적 미채택)

임베딩·벡터DB 미도입. 시도 기록: 사내 ollama `nomic-embed-text`가 **한국어 개념 변별 실패**
(유사도 붕괴)로 미채택. `search()` 내부만 교체하면 되는 슬롯으로 비워둠. 현재는 키워드 +
도메인 동의어 사전(결로≈습기≈김서림, 간극≈갭≈틈) + 그래프 스코어링이 부분 대체
([features/search.md](features/search.md) · [features/nlsearch.md](features/nlsearch.md)).

### ③ 웹에서 자연어 질의 — ✅ 됨

검색창 Enter → `POST /api/nlsearch`: 지역·유형 의도·동의어 해석 + 엔티티 링크 + 1-hop 그래프
확장, 해석 결과("지역: 북미 · 개념: 결로 · 유형: 조치")와 함께 응답. <1초. LLM 경로는
`NL_USE_LLM=1` 옵트인(사내 vLLM 지연으로 기본 OFF, 실패 시 규칙 폴백).

## 4. FMEA 초안 생성 (2D 도면 + BOM → 유사 사례 → 후보·체크리스트·근거 → 초안)

파이프라인 뒷단(②~⑥)은 전부 동작, **입력 앞단(①)만 대체 구현**.

| 단계 | 상태 |
|---|---|
| ① 입력: 2D 도면 이해 | ❌ 도면 파싱/이해 없음 — VLM 확장. 결로 단면 SVG는 *출력* 연출 |
| ① 입력: BOM | 🔶 BOM 파일 파싱 ❌ · 구성 관계(`CONSISTS_OF`)로 정보는 활용 — 파서 추가 수준의 낮은 난이도 확장 |
| ② 유사 조건 과거 사례 검색 | ✅ SIMILAR 가중(0.87 등) + 조건 매칭(광원·형상·시장) 스코어링 |
| ③ 고장모드 후보 | ✅ 유사 프로젝트 발생 이력 수집 + 조건 부스트(북미→FMVSS·슬림→수축·밀폐→결로) |
| ④ 체크리스트 | ✅ 근거·확신도% 붙은 상위 8 |
| ⑤ 근거 출처 | ✅ 항목마다 원본 문서 칩 + 실존 엣지 경로(trace) |
| ⑥ FMEA 초안 생성 | ✅ 13컬럼 DFMEA 워크시트(S·O·D·RPN·우선순위·권고조치·근거) 조건 맞춤 xlsx 다운로드 |

현재 입력은 텍스트 설계 조건(시장·광원·형상·대상 부품). 상세: [features/fmea-draft.md](features/fmea-draft.md) ·
[features/inference.md](features/inference.md)

## 발표용 요약 문장

- 비정형 분석: "사내 문서(xlsx·pptx·docx) 형태별 파싱과 지식베이스 구축은 **동작 완료**,
  이미지·스캔은 **Docling 연동 지점만 설계**, 외부 크롤링은 **미착수(로드맵)**."
- 구조화·검색: "기능은 규칙·그래프 기반으로 충족 — LLM·벡터는 **결정 기록이 있는 보류**
  (한국어 임베딩 실패·vLLM 지연), 좋은 모델 확보 시 `search()`/`nlSearch()`/`infer()` 내부만 교체."
- FMEA 초안: "유사 사례 → 고장모드 후보 → 근거 달린 체크리스트 → **채워진 FMEA 초안**까지 생성
  루프 완성. BOM 입력은 단기, 도면 이해는 장기 확장."
