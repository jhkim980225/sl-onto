# feature: 기능 가용성 — 스키마에서 유도하는 파생값

설계: [multi-canvas](../superpowers/specs/2026-07-20-multi-canvas-design.md) §5

추론·FMEA 초안·모순검사·BOM 정합은 전부 FMEA 객체타입을 하드 가정한다. FMEA 가 아닌 캔버스
(예: 화장품 문서만 넣은 캔버스)에서 이 기능들을 호출하면 빈 결과이거나 에러다 —
**의미를 잃은 버튼을 눌러 빈 화면을 보게 하는 것 자체가 버그다.**

## 매핑 — `lib/capabilities.ts`
```ts
const REQUIRES: Record<Exclude<Capability, "condensation">, string[]> = {
  infer:          ["fm", "cause", "item"],
  fmeaDraft:      ["fm", "action"],
  contradictions: ["fm", "reg"],
  bomCheck:       ["item"],
};
```
`capabilities(metamodel, canvasId)` 는 캔버스 메타모델의 `objectTypes` 집합과 대조해
`Record<Capability, boolean>` 을 돌려주는 **순수 함수**다.

**설정값이 아니라 파생값이다.** 어딘가에 `features.infer = true` 를 저장했다면 스키마를 고치는
순간 어긋난다. 지금은 `◈` 스키마에서 `fm` 타입을 지우면 다음 조회에서 추론 버튼이 자동으로 사라진다.

## 양쪽 다 막는다
| 층 | 처리 |
|---|---|
| 서버 | `requireCapability(cap)` → 요구 타입이 없으면 **409** + 사유. `infer`·`fmea-draft`·`contradictions`·`bom-check`·`condensation` 5개 라우트가 호출 |
| UI | `GET /api/schema` 응답의 `capabilities` 로 버튼을 **감춘다**(`components/Workbench.tsx:132`) |

어느 한쪽만이면 새는 곳이 생긴다. UI 만 막으면 `curl` 한 줄로 뚫리고 로드 전 상태에서 클릭이
빠져나간다. 서버만 막으면 사용자가 누를 수 있는 버튼이 409 를 뱉는다.
`caps` 초기값은 `{}` 라 **로드 전에는 감춰진 상태로 시작한다** — 깜빡임보다 나중에 나타나는 쪽이 안전.

스키마 편집(`SchemaPanel` `onChanged`) 후 `refreshCaps()` 로 다시 조회한다.

## 항상 동작(타입 무관)
그래프·계층·Table·RAW 뷰, 키워드/자연어 검색, 인스펙터, 문서 인제스천, 정리(curate), 품질 지표,
유도 관계, Turtle 내보내기, 객체 Q&A.

## `condensation` 은 `default` 캔버스 전용
결로 시나리오는 노드 id `ILENS`·`FMFOG` 를 하드코딩한다. 타입 유무로 판정할 수 없어
`canvasId === DEFAULT_CANVAS` 라는 별도 규칙을 쓴다(`lib/capabilities.ts:26`). 일반화는 범위 밖.

## 한계 — 매핑이 램프 타입 이름에 묶여 있다
`fm`·`cause`·`item`·`action`·`reg` 는 **램프 FMEA 시드가 정한 타입 id** 다. 화장품 캔버스에서
사용자가 `defect`·`ingredient` 같은 이름으로 같은 구조를 만들면 `REQUIRES` 대조가 전부 실패해
**의미상 가능한 기능도 false 가 된다.** 반대로 이름만 `fm` 으로 맞추면 내용과 무관하게 true 가 된다.

즉 지금 판정하는 것은 "이 캔버스가 FMEA 인가"가 아니라 **"이 캔버스가 램프 FMEA 와 같은 타입 id 를
쓰는가"** 다. 제대로 하려면 타입에 의미 태그(`role: "failure-mode"` 등)를 붙여야 하는데, 캔버스가
하나 더 생기기 전에는 값이 없다.

- 가용성은 **객체타입 존재만** 본다. `bomCheck` 는 `CONSISTS_OF` 관계도 필요하지만 관계타입은
  검사하지 않는다 — `item` 만 있고 관계가 없으면 버튼은 보이고 결과는 빈다.
- 타입이 있어도 **인스턴스가 0개면** 여전히 빈 결과다. 노드 수는 보지 않는다.
- 검증: `lib/capabilities.test.ts`.
