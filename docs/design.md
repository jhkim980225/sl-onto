# design.md — UI 디자인 시스템

시각 언어: **라이트 "워크벤치" + SL Corporation 브랜드 컬러** — 흰 배경 + 딥 네이비(#002157) 텍스트 + 시안 액센트(#00a2e5). SL 실제 사이트 톤(화이트 B2B).
폰트·레이아웃·구조는 데모 그대로, **색감만 SL 라이트 브랜드로 리스킨**.

## 2. 타이포그래피
- 본문/UI: **IBM Plex Sans KR** (400/500/700)
- 코드/수치/라벨/glyph: **IBM Plex Mono** (400/600)
- 기준 크기 14px. glyph 9px, 노드 라벨 12.5px, 히어로 14.5px/700.

## 3. 레이아웃
- 상단바 56px(브랜드·검색·"처음부터"·"▶ 신규 설계 추론 시연").
- 본문 3열 그리드: **좌 252px / 캔버스 1fr / 우 340px**. (≤1180px에서 좌 패널 숨김)
- 하단바 58px: 3단계 스테퍼(흩어진 원천 › 온톨로지 구축 › 신규 설계 추론) + 신규 조건 칩.
- 좌: 원천 데이터 카운트·Docling 파이프·객체/관계 범례. 우: 객체 인스펙터 / 추론 체크리스트.

## 4. 그래프 시각화 스펙
- 노드: 라운드 rect(히어로는 강조 stroke·글로우), 좌측 4px 유형색 바 + glyph + 라벨. `doc`은 작은 원(위성).
- 엣지: 기본 얇은 선, `core` 굵게, `SIMILAR`은 대시. 하이라이트 시 앰버 글로우 + 관계 라벨 표시.
- 포스 시뮬레이션: 반발 + 스프링(엣지) + 앵커(유형별 의미 구역). doc은 부모 근처 짧은 스프링.
- 상태: `dim`(비관련 흐림) · `lit`(점등) · `sel`(선택 beam) · `pulse`(검색/신규 강조) · `spawn`(적재 인).
- **레이아웃: 타입 존 + 방사형 포커스** — 8개 비-doc 유형을 결정론적 중심 좌표로 당겨 **대분류 존**(라벨 `.zone-label`)
  을 만들고(부품·구성 / 고장모드 / 원인 / 조치 / 법규·인증 / 프로젝트 / 마스터 / 고객 스펙),
  노드 클릭 시 1-hop 이웃을 **관련도 티어별 링**(핵심 190 · 주변 320 · 근거문서 450)으로 재배치하며
  비이웃은 dim(포커스). 상세 → [features/그래프-인터랙션.md](features/그래프-인터랙션.md).

## 5. 모션 원칙
- STAGE 2: 코어 객체 순차 스폰 → 관계 스폰 → 근거문서 배치 스트리밍(인제스천 로그·진행바).
- STAGE 3: 신규 노드 pulse → 전체 dim → **웨이브 단위 점등**(유사 프로젝트→고장모드→원인→마스터/법규→조치) + 근거문서 동반 점등 → 체크리스트 순차 등장.
- `prefers-reduced-motion`: 애니메이션 제거, 시뮬레이션 프리롤 후 정지.

## 6. 인터랙션
- 호버: 이웃 하이라이트·나머지 dim. 드래그: 노드 고정 이동. 휠/버튼: 줌, 배경 드래그: 팬.
- 클릭: 우측 인스펙터에 속성·관계·근거. 관계 행 클릭 시 해당 객체로 이동.
- 검색: 입력 시 매칭 노드 pulse + 비매칭 dim.

## 7. 톤 & 카피
- "시연/검토용 초안" 명시. **모든 산출물에 확신도 % 노출**, "최종 판단은 설계 엔지니어".
- 근거칩(문서/사례)을 항상 함께 표기 → 신뢰·추적성.

> 구현 시: 위 토큰을 CSS 변수로 그대로 이식(데모 `:root`와 동일). 색/폰트는 임의 변경 금지.
